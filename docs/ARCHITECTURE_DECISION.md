# ADR-001: 完成済み THJam13 をそのまま土台にする

- 決定日: 2026-07-28 JST
- 状態: Accepted
- 対象: 研究用 Unity / WebGL ビルド

## 決定

`Bagoum/danmokou@cd21229fbce6deddfad360497ead6263c04ba6cf` に含まれる完成済みミニゲーム THJam13 を唯一のゲームプレイ土台にします。

採用対象は次の既存資産です。

- `THJ13 Main Menu.unity`
- `THJ13 Level.unity`
- `THJ13 GameDef.asset`
- `THJ13 Game Data.asset`
- `thjam13_stage.bdsl`
- `thjam13_marisa.bdsl`
- `thjam13_mima.bdsl`
- Danmokou の既存 UI、入力、リプレイ、共通レベル、テスト

## 守る制約

1. ゲームループ、敵配置、弾幕、難易度曲線、UI レイアウトを新規設計しない。
2. ゲームプレイ用 C# / BDSL を新規作成しない。MVP の自作ゲームプレイコードは 0 行。
3. 変更は Inspector、既存 ScriptableObject、参照先、文言、Build Settings、許諾済み素材の差し替えに限定する。
4. 先に動く完成品を維持し、機能追加より削除・既存値の選択・既存 prefab の再利用を優先する。
5. 一回の操作を小さくし、操作前後の Editor スクリーンショットと Console を残す。
6. 原作ゲームの画像・音声・データを取り出して使わない。
7. 別の二次創作者の素材は、明示的な再利用許諾が確認できたものだけ使う。
8. ブラウザ版は無料研究ビルドとし、公開は全素材の権利状態が GREEN になった後だけ行う。

## 採用理由

- Unity 6 系で開くことを前提にした現行プロジェクトである。
- 弾幕ゲームとして完成済みのメニュー、ステージ、プレイヤー、ボス、入力、リプレイ、音声参照、テストが揃っている。
- コード部分は MIT で、ライセンス表示の仕組みも既存 Game Data に組み込まれている。
- THJam13 はすでに東方二次創作ゲームとして成立しており、一般的な 2D テンプレートを弾幕ゲームへ改造するより変更量が小さい。
- Danmokou には EditMode / PlayMode テスト資産があり、ゼロからテスト設計する必要がない。

## 不採用または保留

### Unity 2D Game Kit

完成例とノーコード編集には優れるものの、横スクロール探索ゲームから弾幕ゲームへのゲームループ変更が大きくなるため、今回の最短経路では不採用です。

### Happy Harvest / Dragon Crashers

見栄えのよい完成サンプルですが、農場／アイドル RPG の構造を弾幕へ変える必要があり、「設計しない」という制約に反します。

### 完全自作

禁止です。完成品で解けない問題は、まず機能を落とすか別の完成済みサンプルへ乗り換えます。

## 変更予算

| 種別 | MVP 予算 |
|---|---:|
| 新規ゲームプレイコード | 0 行 |
| 新規弾幕パターン | 0 |
| 新規シーン | 0 |
| 新規 prefab | 0 |
| 既存参照の差し替え | 許可 |
| 既存文言の変更 | 許可 |
| CI / E2E /運用設定 | 必要最小限を許可 |

## 撤退条件

次のいずれかが起きたら、その場で実装を増やさずベース選定へ戻ります。

- THJam13 を起動するためにゲームプレイコードの修正が必要になる。
- WebGL 化に固有ゲームロジックの改修が必要になる。
- 使用中の主要素材の再配布条件が確認できない。
- Unity GUI 操作が再現不能で、同じ設定を ScriptableObject / YAML / API で選べない。

## 成功条件

- メニューから既存 THJam13 レベルを開始できる。
- 移動、低速移動、ショット、モード切替が既存操作のまま動く。
- EditMode / PlayMode テストが実行され、結果が保存される。
- WebGL が Chromium で Canvas を表示し、入力を受け、致命的な JavaScript / WebAssembly エラーを出さない。
- 起動時、入力後、クリアまたはゲームオーバー時のスクリーンショットを採取できる。
- ライセンス／クレジットがゲーム内または同梱文書から確認できる。
